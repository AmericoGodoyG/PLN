# Introdução ao SpaCy

## 🧠 O que é?
O **SpaCy** é uma biblioteca open-source de Processamento de Linguagem Natural (PLN) em Python, desenvolvida especificamente para uso em produção. Ele foi construído para ser extremamente rápido e produtivo, auxiliando desenvolvedores a criarem softwares e produtos de IA para compreender e manipular textos volumosos. 

Diferente de bibliotecas voltadas puramente para o ensino ou pesquisa exploratória, o SpaCy foca em providenciar os algoritmos mais eficientes e uma arquitetura baseada em etapas de processamento contínuo (pipelines).

## 🛠️ Principais Aplicações
- **Tokenização:** Separação do texto em unidades atômicas (tokens, como palavras ou pontuações).
- **Lematização e Stemming:** Redução de palavras à sua forma base ou de dicionário.
- **POS Tagging (Classificação Gramatical):** Identificação de substantivos, verbos, adjetivos, etc.
- **Reconhecimento de Entidades Nomeadas (NER):** Capacidade de localizar e classificar nomes de pessoas, organizações, locais, moedas, dentro de grandes blocos de texto.
- **Análise de Dependências:** Análise da gramática para entender as relações entre duas ou mais palavras dentro de uma frase.
- **Pré-processamento:** Tratamento de texto padrão antes de alimentá-lo em modelos avançados de Deep Learning.
